================================================================
     CCTV AI DETECTION — PANDUAN INSTALASI & MENJALANKAN
================================================================

PRASYARAT (Lakukan SEKALI di perangkat baru):
--------------------------------------------
1. Install Python 3.11 atau lebih baru dari:
   https://www.python.org/downloads/

   ⚠️ PENTING: Saat instalasi Python, WAJIB CENTANG KOTAK:
   [v] "Add Python to PATH" (atau "Add python.exe to PATH")
   Jika tidak dicentang, Python tidak akan terbaca di Command Prompt!

2. Pastikan koneksi internet aktif untuk download dependensi AI.


================================================================
LANGKAH INSTALASI OTOMATIS & RUN (WINDOWS):
================================================================
1. Extract file ZIP ke folder mana saja.
   Contoh: D:\CCTV AI DETECTION\ atau C:\CCTV AI\

2. Buka folder hasil extract tersebut.

3. Double-click file: setup.bat

4. Sistem akan otomatis mendeteksi status instalasi:

   A. JIKA BELUM TERINSTALL DI PERANGKAT INI:
      - Layar akan menampilkan: [STATUS: SISTEM BELUM TERINSTALL]
      - Pilih mode instalasi:
          [1] Install Lengkap (Rekomendasi: AI deps + .env + shortcut)
          [2] Install Cepat   (Hanya library AI, skip konfigurasi)
          [3] Keluar
      - Tekan Enter. Sistem akan otomatis mendownload semua library AI
        (OpenCV, PyTorch, YOLOv8, FastAPI). Progres download akan
        terlihat jelas di layar (estimasi 5-15 menit).
      - Jika memilih [1], masukkan Telegram Bot Token & Chat ID
        (opsional, bisa tekan Enter untuk isi nanti).
      - Pilih 'y' jika ingin membuat shortcut "CCTV AI" di Desktop.
      - Setelah selesai, tekan Enter: SISTEM AKAN LANGSUNG JALAN!

   B. JIKA SUDAH PERNAH DIINSTALL SEBELUMNYA:
      - Layar akan menampilkan: [STATUS: SISTEM SUDAH TERINSTALL]
      - Cukup tekan [1] lalu Enter: CCTV AI langsung berjalan otomatis
        tanpa perlu download ulang!
      - Ada juga opsi [2] jika ingin Install Ulang / Perbarui Dependensi.


================================================================
PENGGUNA LINUX / MACOS (CROSS-PLATFORM):
================================================================
Buka Terminal di folder CCTV AI, lalu jalankan salah satu:
  - Linux/macOS : bash setup.sh
  - Universal   : python3 launch.py


================================================================
CARA MENJALANKAN APLIKASI SETELAH TERINSTALL:
================================================================
Pilih salah satu cara termudah:
  1. Double-click file: setup.bat (otomatis deteksi & langsung jalan)
  2. Double-click shortcut "CCTV AI" di Desktop (jika sudah dibuat)
  3. Double-click file: run.py
  4. Mode Hening (tanpa jendela terminal): Double-click file cctv.pyw

Dashboard Web CCTV AI akan terbuka otomatis di browser Anda:
  http://localhost:8000


================================================================
CARA MENDAPATKAN TELEGRAM BOT TOKEN & CHAT ID:
================================================================
Bot Token (untuk kirim foto deteksi ke Telegram):
  1. Buka aplikasi Telegram, cari bot: @BotFather
  2. Ketik /newbot lalu ikuti petunjuk nama bot Anda
  3. Salin (copy) HTTP API Token yang diberikan
  Contoh: 123456789:ABCdefGHIjklMNOpqrSTUvwxYZ

Chat ID (ID akun/grup penerima notifikasi):
  1. Buka Telegram, cari bot: @userinfobot
  2. Klik Start atau ketik /start
  3. Bot akan membalas dengan ID Anda
  Contoh: 123456789 (pribadi) atau -123456789 (grup)

Catatan: Konfigurasi ini disimpan di file .env. Anda dapat mengedit
file .env menggunakan Notepad kapan saja.


================================================================
TROUBLESHOOTING (SOLUSI MASALAH):
================================================================
Masalah: "Python tidak ditemukan di PATH"
Solusi : Install ulang Python dari python.org dan pastikan centang
         "Add Python to PATH".

Masalah: Jendela tertutup atau koneksi putus saat download dependensi
Solusi : Koneksi internet terputus. Pastikan internet stabil, lalu
         double-click setup.bat kembali.

Masalah: Dashboard tidak muncul di browser
Solusi : Buka browser secara manual (Chrome/Edge/Firefox), ketik alamat:
         http://localhost:8000

Masalah: Notifikasi Telegram tidak masuk ke HP
Solusi : Buka file .env dengan Notepad. Pastikan TELEGRAM_BOT_TOKEN
         dan TELEGRAM_CHAT_ID sudah terisi dengan benar tanpa spasi.

Masalah: URL RTSP kamera CCTV tidak tampil
Solusi : Buka file config\config.yaml dengan Notepad. Sesuaikan alamat
         IP/RTSP kamera CCTV Anda pada bagian rtsp_url.
