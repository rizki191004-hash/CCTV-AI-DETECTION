================================================================
     CCTV AI DETECTION — PANDUAN INSTALASI & MENJALANKAN
================================================================

PRASYARAT (Lakukan SEKALI di perangkat baru):
--------------------------------------------
1. Pastikan koneksi internet aktif untuk proses instalasi otomatis pertama kali.
2. (OTOMATIS) Python 3.11 akan diunduh dan dipasang secara OTOMATIS oleh setup.bat
   jika belum ada di komputer Anda! Tidak perlu mengunduh Python secara manual.
   (Namun jika ingin menginstal manual, silakan unduh Python 3.11+ dari python.org
   dan pastikan centang kotak "Add Python to PATH").


================================================================
LANGKAH INSTALASI OTOMATIS & RUN (WINDOWS):
================================================================
1. Extract file ZIP ke folder mana saja.
   Contoh: D:\CCTV AI DETECTION\ atau C:\CCTV AI\

2. Buka folder hasil extract tersebut.

3. Double-click file: setup.bat

4. Menu Utama setup.bat menyediakan 3 pilihan ringkas:
   [1] Install Semua Otomatis Sistem & Shortcut Desktop
   [2] Hapus Semua Komponen Sistem & Shortcut (Uninstall)
   [3] Keluar (Exit)

   - CARA INSTALL OTOMATIS:
     Pilih [1] lalu tekan Enter (atau langsung tekan Enter).
     Sistem akan otomatis mendeteksi ketersediaan Python (mengunduh & memasang
     Python 3.11 resmi jika belum ada), memasang semua library AI (OpenCV, PyTorch,
     YOLOv8, FastAPI), serta membuat 1 shortcut "CCTV AI" di Desktop Anda.
     Setelah selesai, jendela CMD akan MENUTUP SENDIRI dalam 3 detik!

   - CARA MENGAKTIFKAN CCTV AI:
     Cukup double-click shortcut "CCTV AI" di Desktop Anda!
     Sistem CCTV AI langsung aktif di background dan membuka web browser:
       http://localhost:8000
     (Jika di-double-click lagi saat CCTV aktif, muncul kotak dialog
     pilihan untuk mematikan CCTV atau membuka dashboard).

   - CARA MENGHAPUS / BERSIHKAN KOMPONEN (UNINSTALL):
     Buka setup.bat, pilih [2] lalu tekan Enter.
     Shortcut Desktop, database event, dan seluruh proses latar belakang
     akan dibersihkan secara otomatis, lalu CMD menutup sendiri.


================================================================
PENGGUNA LINUX / MACOS (CROSS-PLATFORM):
================================================================
Buka Terminal di folder CCTV AI, lalu jalankan salah satu:
  - Linux/macOS : bash setup.sh
  - Universal   : python3 launch.py


================================================================
CARA MENJALANKAN APLIKASI SETELAH TERINSTALL:
================================================================
Pilih salah satu cara termudah:
  1. Double-click file: setup.bat (otomatis deteksi & langsung jalan)
  2. Double-click shortcut "CCTV AI" di Desktop (1-click start/stop)
  3. Double-click file: run.py
  4. Mode Hening (tanpa jendela terminal): Double-click file cctv.pyw

Dashboard Web CCTV AI akan terbuka otomatis di browser Anda:
  http://localhost:8000


================================================================
CARA MENDAPATKAN TELEGRAM BOT TOKEN & CHAT ID:
================================================================
Bot Token (untuk kirim foto deteksi ke Telegram):
  1. Buka aplikasi Telegram, cari bot: @BotFather
  2. Ketik /newbot lalu ikuti petunjuk nama bot Anda
  3. Salin (copy) HTTP API Token yang diberikan
  Contoh: 123456789:ABCdefGHIjklMNOpqrSTUvwxYZ

Chat ID (ID akun/grup penerima notifikasi):
  1. Buka Telegram, cari bot: @userinfobot
  2. Klik Start atau ketik /start
  3. Bot akan membalas dengan ID Anda
  Contoh: 123456789 (pribadi) atau -123456789 (grup)

Catatan: Konfigurasi ini disimpan di file .env. Anda dapat mengedit
file .env menggunakan Notepad kapan saja.


================================================================
TROUBLESHOOTING (SOLUSI MASALAH):
================================================================
Masalah: "Python belum terpasang di perangkat ini"
Solusi : setup.bat akan otomatis mendownload dan menginstall Python 3.11 resmi.
         Pastikan koneksi internet aktif selama instalasi pertama berjalan.
         Jika jaringan Anda memblokir unduhan otomatis, unduh manual dari
         https://www.python.org/downloads/ dan centang "Add Python to PATH".

Masalah: Shortcut Desktop tidak muncul
Solusi : Double-click setup.bat, lalu pilih opsi [2] "Buat / Perbaiki
         Shortcut CCTV AI di Desktop".

Masalah: Jendela tertutup atau koneksi putus saat download dependensi
Solusi : Koneksi internet terputus. Pastikan internet stabil, lalu
         double-click setup.bat kembali.

Masalah: Dashboard tidak muncul di browser
Solusi : Buka browser secara manual (Chrome/Edge/Firefox), ketik alamat:
         http://localhost:8000

Masalah: Notifikasi Telegram tidak masuk ke HP
Solusi : Buka file .env dengan Notepad. Pastikan TELEGRAM_BOT_TOKEN
         dan TELEGRAM_CHAT_ID sudah terisi dengan benar tanpa spasi.

Masalah: URL RTSP kamera CCTV tidak tampil
Solusi : Buka file config\config.yaml dengan Notepad. Sesuaikan alamat
         IP/RTSP kamera CCTV Anda pada bagian rtsp_url.
